# 加密配置与账号备份

2026-09-20。支持手动迁移应用配置和平台账号；不会自动把账号上传至 WebDAV。

## 使用方式

1. 在哔咔、JM、绅士漫画登录页勾选“记住账号密码（加密保存）”，登录并通过账号验证后保存。默认勾选，用户可取消。旧账号只有 Token/Cookie，需重新输入密码登录一次才能记住密码。
2. 会话过期后点击“使用已保存账号登录”。密码不回填到输入框；只有用户点击才重新提交登录，不做后台循环重试。
3. “设置 → 数据与同步 → 导出配置与账号”，设置并再次输入 8–128 位备份密码，选择是否包含账号，再选择保存位置。生成 `PiComic-日期.picomic`。
4. 新设备选择“导入配置与账号”，输入备份密码，预览数据冲突及账号列表。本机已有账号默认不替换；新账号默认选中。确认后普通数据合并，选中的平台账号逐个替换。
5. 导入会话进入“待验证”，到账号页验证；已失效且记住密码的账号可一键重新登录。普通旧版 JSON 仍可导入，但没有账号凭据。

忘记备份密码将无法恢复文件。它与平台密码、设备解锁密码是不同的密码。

## 保存范围和删除语义

| 内容 | 本机 | 手动加密备份 | WebDAV/旧版普通数据合同 |
| --- | --- | --- | --- |
| 书架、历史、可迁移偏好 | Room 与兼容偏好投影 | 包含 | 包含 |
| 六组平台会话、账号标识 | Android Keystore 加密 | 可选，默认包含 | 排除 |
| 哔咔/JM/绅士漫画账号密码 | 勾选记住并验证成功后加密 | 跟随账号选项 | 排除 |
| 代理/WebDAV 密码、设备密钥、目录授权、漫画图片 | 各自原有存储 | 排除 | 排除 |

“忘记已保存的密码”只删除记住的账号密码，保留有效会话；“清除本地账号”同时删除会话和密码。会话到期只删除会话。登录失败、网络异常、取消或晚到的旧请求不会覆盖现有账号；切换账号不会继承旧账号密码。取消记住密码后的成功登录会移除该来源此前保存的密码。

## 格式与边界

- 本机账号记录仍在 `noBackupFilesDir/credentials`，使用 Android Keystore 的 AES-GCM 密钥与原子文件写入。新版记录 v3 支持会话和可选密码，兼容读取原有 v1/v2 记录。不同设备使用不同本机密钥。
- 文件上限 12 MiB；标头为 8 字节 `PICOMIC\0`、版本字节 1、16 字节随机盐和 12 字节随机 nonce。版本 1 固定使用 PBKDF2-HMAC-SHA256、600,000 次迭代、256 位派生密钥以及 AES-256-GCM、128 位认证标签；完整标头作为 AAD。每次导出生成新的盐和 nonce。
- 加密载荷是带版本的二进制封装，内含原有严格 JSON 数据合同及平台账号记录；没有明文临时文件。解密成功仍要校验版本、字段、来源白名单、凭据种类、大小、重复记录和尾随字节。代理、端点配置及任意路径不从账号记录导入。
- 备份密码与解密账号仅在操作内存中使用，不进入普通设置、日志、可保存的界面状态；密码对话框禁止截图，切到后台清空输入，关闭/离开预览清理账号字节。无法承诺 JVM/Android 的所有内部堆副本都可强制清零。
- 导入前核对普通数据快照和账号指纹，账号写入前再次核对。导入账号会使旧请求失效，始终先设为待验证；只有密码的记录为会话失效状态，不伪装为已登录。
- 普通数据使用 Room 事务；各平台账号使用独立原子密文文件，两者没有跨存储事务。普通数据成功后如果个别账号写入失败，会报告失败来源，成功项保留；重新预览后可重试。用户确认后的本地写入不会因离开页面中途取消，进程被系统终止仍可能留下已完成的部分。

算法依据：[Android 密码学指南](https://developer.android.com/privacy-and-security/cryptography)、[OWASP 密码派生建议](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)、[OWASP 加密存储指南](https://cheatsheetseries.owasp.org/cheatsheets/Cryptographic_Storage_Cheat_Sheet.html)。安全性依赖备份密码强度，未使用固定密钥或仅 Base64 编码。

## 验证

- JVM 75 项通过，包括新增独立 Python 加密向量、Unicode 密码、随机盐/nonce、错误密码、篡改/截断/超限，旧账号格式、失败替换、记住/忘记密码、过期后重新登录、账号导入与迟到请求。
- API 26 / Android 8 与 API 36 / Android 16 各 16 项备份与登录专项通过：独立加密向量、两把 Keystore 密钥间迁移、错误密码不写账号、结构校验、预览内存所有权、密码对话框、HTTP 登录流程、普通数据合同与事务回滚。完整设置流程测试覆盖加密写入文件、错误密码、正确解密预览与后台清理，仅用测试 URI 回调替代系统文件选择器。
- Debug/Release Lint 均无错误；Release 已生成并校验正式证书、Android 8 可用的 v2 签名、arm64-v8a 架构及更新清单。APK 为本地 `0.3.0` 候选，未推送发布标签。
- 测试全部使用合成账号、口令和 HTTP 夹具；不使用真实平台密码。Android 验证为模拟器，不等同于实体机性能或所有系统文件提供方验收。
