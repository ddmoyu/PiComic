# 内容接入与 JM 验证

更新：2026-09-20。当前开发版 0.3.0-alpha；这是持续开发记录，不是六来源全部通过的准入结论。

## 已实现

- 真实内容模型采用来源、作品字符串 ID、实际章节 ID 和页 ID，搜索分页取消过时请求并去重。
- 哔咔搜索、分类、详情、完整章节/页面分页接入同一会话验证链路。真实内容进入本地收藏、历史和三种阅读模式；账号/网络变更使旧请求失效。
- 默认 App 读取真实来源。原创示意目录仅在显式开启 Debug 演示开关时使用，Release 无该入口。
- JM 使用独立 `jm-cookie-1.8.2-v1`：每请求时间、签名和 AES 响应解码绑定；没有混用 2.x JWT profile。
- JM 匿名分类/搜索/详情/章节、原生登录候选、独立资料验证、加密 Cookie、会话恢复和来源隔离。已有会话失效不会悄悄退到匿名身份。
- JM 图片处理读取章节页面中的 photo/scramble 参数，保留文件名和算法版本。原尺寸完成条带重排后原子提交缓存，再交给 Coil/阅读器；GIF 和已还原图片不重复处理。
- API 可信候选选择与匿名可用性检测；图片分流通过 setting 独立解析，换 API 不能把旧线路 Cookie 转发过去。
- 持久本地收藏、阅读历史、按来源搜索历史；未知来源行保留在数据库，展示已知来源时不使整张书架失效。

## 实测范围

Windows 上以当前显式 HTTP 代理、正常 TLS、匿名请求核对 JM：setting、categories、空结果 search、categories/filter、album、chapter、chapter_view_template。只保留字段、计数和协议参数，不保存作品正文、封面或平台图片。

setting 返回 1.8.2；列表一页 80 项；全册没有 series 时使用稳定 `whole`；chapter ID 与请求 photo ID 一致；页面模板提供匹配的 aid 与 scramble 参数。具体作品、标签和页 URL 不进入验证文档。

D2 全量：JVM 36 项通过；模拟器 41 项常规测试通过，显式联网测试 1 项未启用；Debug 构建、Lint 通过。JM 首轮定向回归：JVM 总计 41 项、模拟器 11 项通过，包括并发响应使用各自时钟、编码、全册、错误元数据、Cookie 原点隔离、跳转/限流和合成图逐像素重排。新增阅读显示偏好和数据库升级回归继续执行，最终结果记录在完整清单。

真实哔咔/JM 账号、首中末真实图片、实体手机和下载离线验收仍待执行。GET /login 的已认证用户资料结构目前由参考协议与夹具约束，尚无真实用户会话的确认；校验失败不会保存为已登录。
