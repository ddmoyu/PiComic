# 连续阅读手势原型验证

环境：Chrome headless，390 × 844 移动视口及 1440 × 1000 桌面视口，鼠标、滚轮及浏览器触屏输入。仅验证 HTML 原型，不代表 Android 真机验收。

- 通过：鼠标按住拖动滚动；拖动不误触工具栏，单击仍可切换工具栏
- 通过：图片仍无页码插入和间距，懒加载图片预留完整尺寸
- 通过：章末最后一张图片贴合视口底部；工具栏显示或隐藏均无固定空白
- 通过：到达底部不换章；短上拉回弹；达到阈值松开后只进入下一章并保存进度
- 通过：上拉后撤回及系统取消手势均不换章
- 通过：滚轮短滚不误翻，持续向下滚动后完成换章
- 通过：换章后连续四批大幅滚轮输入被拦截，保持下一章首屏；停止后新滚动恢复
- 通过：最后一章仅显示紧凑悬浮提示并自动消失
- 通过：返回、切换阅读模式及打开面板会取消待执行换章，关闭面板后手势可继续使用
- 通过：移动触屏输入支持继续上拉、松开换章
- 通过：桌面预览显示换章动画，反馈完整位于工具栏上方，残余滚轮不会滚离新章首屏
- 通过：无 JavaScript 运行错误
