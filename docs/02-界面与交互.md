# 02 · 界面与交互

## 1. 设计依据

原版 PicaComic 在 `lib/main.dart` 使用 `ColorScheme.fromSeed`、Material 3、动态/手动主题色和明暗主题。本稿沿用这种视觉方向：浅色低对比背景、蓝色主色、圆角表面、左封面、右信息的作品列表、胶囊筛选器。并非照搬全部桌面/跨平台布局。[固定源码证据见 PICA-UI](evidence/source-index.md)

手机是主要设计对象。简体中文、触摸优先，支持 Android 返回手势和系统字体缩放。底部导航是原生 App 导航，不使用网页顶部菜单作为产品结构。

界面图标统一采用官方 Phosphor Regular 矢量库；收藏选中态使用同库的填充心形。默认图标 24 dp、图标按钮点击区域 48 dp，保留中文无障碍名称。不得自行手绘图标路径；版本、许可及生成方式见 [图标资源说明](../third_party/phosphor-icons/README.md)。启动图标继续采用已确认的 D7 标志。

## 2. 信息架构

| 一级入口 | 页面 | 主任务 |
|---|---|---|
| 探索 | 按平台浏览作品、搜索 | 找作品 |
| 分类 | 当前来源分类、标签结果 | 按题材找作品 |
| 书架 | 收藏、历史、下载 | 管理和继续阅读 |

一级页面左上显示页面标题，右上固定搜索和设置按钮。底部导航仅显示图标，保留选中胶囊高亮、无障碍名称和长按提示；图标顺序为探索、分类、书架。

探索和分类都使用顶部横向平台 Tab，直接点击或横向滚动切换六组来源，不使用下拉菜单/选择面板。平台顺序为 Hitomi、禁漫天堂（jmcomic）、绅士漫画、nhentai、EH / EX、picacg；优先展示可匿名浏览的来源，JM 固定第二位，登录及权限要求较多的来源后置。搜索和账号管理使用同一顺序；EH/EX 模式仍在该来源设置中切换。首次使用默认 Hitomi，已有用户保留上次选择。两页共享当前平台，分别保存每个平台的内容与滚动位置。

标题栏和平台 Tab 固定在页面顶部，底部导航固定，仅中间内容区域纵向滚动。详情、分类结果、搜索和设置为二级路由，阅读器为全屏路由，进入后隐藏底部导航；返回恢复发起页面和当前平台。

### 页面职责与入口去重

取消“我的”一级页面。底部仅探索、分类、书架三个图标；右上角齿轮统一打开同一个设置页面，从任何页面进入都保留返回来源。

| 用户任务 | 唯一常驻管理入口 | 内容 |
|---|---|---|
| 收藏作品 | 书架 → 收藏 | 查看收藏、打开详情继续阅读 |
| 查看阅读记录 | 书架 → 阅读历史 | 按最近阅读排序，恢复章节和页码 |
| 管理下载任务 | 书架 → 下载管理 | 队列、暂停/继续、取消、离线阅读 |
| 修改下载行为 | 设置 → 数据与同步 → 下载偏好 | 下载目录、并行数；不展示任务列表 |
| 调整 App / 来源 | 顶部设置 | 账号、漫画源、筛选、阅读/外观、更新、数据、日志、网络和关于 |

设置不再重复列出书架、阅读历史和下载管理；Logo/介绍统一放在关于页。探索不显示续读卡。续读从书架阅读历史或作品详情进入；详情下载和错误页“查看下载”进入同一书架下载 Tab，不创建另一套管理页面。底部选中书架后可切换三个标签，设置返回保持所选标签。

## 3. 页面规格

### 探索与搜索

- 顶栏：左侧“探索”，右侧搜索、齿轮设置；下一行固定平台 Tab，选中项用主色文字和下划线表示。
- 内容页直接展示当前漫画源的作品列表，移除最新/热门/推荐筛选及对应栏目标题。平台 Tab 专门切来源。
- 探索页来源已由选中的平台 Tab 表明，作品行不再重复显示来源名称；末行保留作品 ID 和语言。书架等可能混合来源的列表保留来源标识。
- 探索禁止显示“继续上次阅读”“继续上次的故事”或其他续读卡、横幅、快捷入口，即使已有阅读历史也不显示。此要求同时适用于 Android 界面、HTML 原型和设计方案；恢复进度只从书架阅读历史或作品详情进入。
- 搜索独立页面：固定返回按钮、搜索框、单行“搜索”按钮；下方固定六漫画源横向 Tab。空关键词只显示最近搜索及简短引导，不显示“随便看看”或推荐书目。支持键盘提交、关键词一键清空、最近记录清空与结果分页。
- 搜索中切换漫画源保留输入框的当前关键词，并在目标源重新搜索；空关键词保持历史页。默认继承进入时的来源，选择后同步当前浏览来源，返回发起页面时使用所选来源。列表与历史仍按来源归属管理，不把各源结果合并。原生请求需取消旧任务并校验 sourceId/query，不能让旧响应覆盖新结果。探索/分类的栏目和滚动状态继续按源保存。

### 分类

- 顶栏：左侧“分类”，右侧搜索、设置；下一行是与探索一致的平台 Tab。
- 内容显示平台名称、快捷入口及分组分类/标签按钮，按钮自然换行；保留各平台的分类体系，不用一套统一题材覆盖所有平台。
- 分类按钮采用接近原版的紧凑浅底圆角标签；可见高度 32 dp，通过外侧留白保留至少 48 dp 点击区域，不能把整个点击区域都画成大按钮。缩小横向内边距与行间距；分类内容和顺序不变。
- 点击分类进入当前平台的分类结果页；返回恢复平台和滚动位置。切平台仍停留在分类页，不跳到探索。
- 顶部搜索默认使用当前平台，进入搜索页后可通过 Tab 选择其他平台；设置提供账号管理、网络与阅读外观入口，返回恢复原页面。

### 详情

- 顶栏左侧返回、中间“作品详情”、右侧刷新按钮，三者同一行；刷新不放在封面旁的来源行。下方展示封面、标题、来源、作者/页数/更新信息；缺失字段直接省略。
- 主操作“开始阅读”或“继续阅读”；次操作“收藏”“下载”。收藏有填充图标与文字状态。
- 简介折叠；信息区该项统一标为“标签”，不并列显示“分类 / 标签”；标签可搜索；目录标记已读、当前、已下载状态。
- 网络收藏为后续独立操作，不与本地收藏一个按钮混用。

### 阅读器

- 页面优先，深色全屏背景；首次进入显示简短手势提示，可关闭。
- 点击中部切换工具栏；左右点击区域按阅读方向前后翻页；音量键翻页为可选项。
- 顶栏：返回、标题/章节、阅读设置；底栏：页码滑块、前后章、目录。
- 纵向模式以连续滑动为主，明确当前页；缩放后先处理图片移动，再处理容器滚动。
- 纵向连续模式滚动到底后，继续上拉显示阻尼与进度反馈，达到阈值松开后进入下一章；仅到达底部不跳章。最后一章继续上拉仅显示短暂的小型悬浮提示。
- 亮度只改变当前窗口；离开后恢复应用默认亮度，不修改系统全局亮度。

### 书架/历史/下载

- 书架二级标签：收藏、阅读历史、下载管理。空态有“去探索”操作。
- 历史展示章节/页码和阅读时间；继续阅读恢复准确位置。
- 下载展示字节或页数进度、排队/进行中/暂停/失败/完成状态。
- 暂停保留已完成页；取消和删除是不同操作。删除已下载文件前确认，取消确认则无变化。

### 账号管理

入口统一命名“账号管理”。页面按平台纵向分组，用标题与分隔线组织；已登录时按平台能力显示账号、用户名、等级、简介，缺失字段不占位。提供重新登录和退出登录；未登录时提供该平台支持的登录方法。重新登录返回原平台分组和滚动位置。

Cookies/Token/API Key 会话信息默认折叠，只显示类型、登录方式和验证状态，不直接展示或复制原始凭据。普通用户无需在此页面手动管理 Token。

六个来源独立显示“未登录/已登录/已过期/无需登录/待验证”。hitomi 不伪造账号密码登录。EH/EX 显示会话状态及 EX 访问验证结果；NH 提供 API Key 与网页登录能力，最终入口以联调结果决定。

密码输入可切换可见性；默认不记住密码，仅保存会话。开启“记住密码以便自动重新登录”才长期保存加密密码。网页登录成功须再请求平台接口确认。

网页登录为独立二级页面：顶栏返回/取消、平台标识、WebView 登录区域。完成平台登录后自动进入“获取凭据 → 验证会话 → 返回”；缺失或失效时留在流程内并给出可操作反馈。重新登录或验证中取消不污染旧会话，返回后保留之前的阅读任务。[原生处理规格](06-网络登录与会话.md)

### 网络与线路

- 默认“跟随系统”：兼容系统 VPN 和系统代理，产品文案不声称 App 自带代理服务。
- 可选“自定义 HTTP 代理”：主机、端口、可选代理认证；保存后重建共享网络配置。
- 首版不提供强制直连开关；高级 SOCKS5 作为后续能力，不在原型中假装已经可用。
- 每来源设置 API 线路和图片线路。显示当前选择、最近检测状态和失败原因；不展示凭据。
- “检测连接”必须用该来源当前网络策略，区分 API 可达、认证状态、图片可达。

### 检查更新

- 入口：“设置 → 更新”，副标题显示当前版本与 GitHub Releases。
- 独立页面用紧凑信息卡显示当前版本和稳定版渠道，提供检查按钮、最后检查时间；支持手动检查和可选启动检查，不打断阅读。
- 发现新版本后展示版本、发布日期、大小、更新说明与“查看 GitHub Release”；下载可暂停、继续、取消。
- 文件校验完成才显示“安装更新”。安装权限与系统确认在用户点击后出现，取消后仍可继续使用当前版本；不能将打开安装器视作已完成更新。
- 无更新、网络失败、限流、无发布、不兼容和校验失败分别展示。详见[更新与发布规范](11-应用更新与GitHub发布.md)。

### 关于与更新的分工

关于只承载 Logo、应用介绍、项目地址和问题反馈；不再展示原型版本号或技术栈。当前版本、发布渠道、检查记录、新版说明与下载/安装集中在更新页，更新页不再重复 Logo 和应用介绍。具体版本的 Release 链接保留在更新流程中。

## 4. 状态与反馈

| 状态 | 用户看到什么 | 恢复动作 |
|---|---|---|
| 首次加载 | 封面骨架/进度 | 可返回或取消 |
| 空内容 | 没有找到相关作品 | 改关键词/条件 |
| 网络失败 | 连接失败，检查系统代理或线路 | 重试/网络设置 |
| 会话过期 | 登录已过期，阅读位置已保存 | 重新登录 |
| 网页验证 | 需要完成网站验证 | 打开验证页 |
| EX 无权限 | 当前账号尚不能访问 EX | 查看账号/用户选择切到 EH |
| 图片额度用尽 | 暂时无法继续加载图片 | 停止预读/查看来源状态 |
| 单页失败 | 该页重试按钮 | 仅重试该页 |

状态必须用图标与文字共同表达，不能只用红/绿色。Toast 只承载短结果，关键异常留在页面上。

## 5. 视觉与适配基线

主色 `#405FAD`，浅色背景 `#F9FAFF`，表面 `#FFFFFF`，主文本 `#202431`；暗色背景 `#12151E`，主色 `#AEC6FF`。正文 16 sp、次要信息 12–14 sp、标题 20–24 sp；点击目标至少 48 dp；主要卡片圆角 16 dp，底部面板 24 dp。

探索、收藏和阅读历史采用左封面、右信息的单列列表；章节采用单行虚拟列表，不改成按钮网格。宽窗口限制内容宽度并保持可达，不增加专属双栏产品结构。阅读页使用全部窗口，按图片比例适配。大字体时允许换行、增高和滚动。

界面优化以当前 Android 代码重新运行后的截图为依据。只调整已有内容的视觉呈现，不增加功能、导航入口、推荐区或续读卡；文档中尚未落地的设想不自动纳入本轮优化。Android 以 dp、Insets、真实字体缩放验收。

## 设置页分组与二级导航

首页按“内容与来源、阅读体验、APP、网络与关于”分组。账号管理、漫画源、内容筛选、阅读、外观、更新、数据与同步、日志、代理、关于各有独立入口。平台设置横向 Tab，语言多选、枚举单选、布尔 Switch，危险动作确认。完整页面树、排版与字段见[设置与偏好规格](12-设置与偏好规格.md)。

### 连续阅读图片衔接

纵向连续模式中，图片之间不显示页码、标题、分隔线或额外间距，图片以 block 布局无缝衔接。页码和进度只显示在可隐藏的阅读工具栏；隐藏工具栏后不保留浮动页码。保留图片原有内容与边缘，不自动裁掉原图留白；章节页序、进度记录和跳页功能保持可用。原生 LazyColumn 的 item 间距为 0 dp。

### 连续阅读章末手势

- 鼠标按住画面向上拖动与触屏上拉一致，向下拖动可以回看。超过拖动阈值后不触发工具栏显隐，单击仍切换工具栏。
- 普通滚动到达底部不会换章；继续上拉时，页尾以渐强阻尼上移，底部逐渐露出下一章画面，配合小型灰色进度反馈。到底时显示“第 N 章已读完 · 继续上拉”；上拉时提示从“继续上拉进入下一章”变为“松开进入第 N 章”。累计上拉约 180 px 后松开，下一章画面在约 640 ms 内从底部上移接替当前画面，像接上下一段画卷；不足阈值会收回预览并回弹。目标章节仍仅使用小型灰色提示。
- 上拉不足阈值、反向撤回或手势取消时回弹。滚轮在底部持续向下滚动累计意图，停止后确认换章；滚轮采用位移折减、事件数量和持续时间共同判定，短滚或少量大幅滚动不换章。换章后会拦截残余滚轮输入，滚轮停止至少 700 ms 后才能重新滚动，避免同一轮滚动跨越多个章节。
- 最后一章只显示“已经是最后一章了”悬浮提示，约 1.6 秒后消失；不插入章末占位内容、不打开弹窗。
- 章末提示使用紧凑的半透明深灰小浮层、浅灰文字及小型灰色进度环，不使用绿色、高亮边框或明显阴影；上拉、就绪、换章和最后一章保持同一低调风格。反馈浮于画面之上，不参与图片排版；图片之间继续保持零间距。返回、切换模式或打开操作面板时不得延迟跳章。

### 章末底部留白

连续阅读的最后一张图片直接贴合阅读视口底部，不为换章提示或工具栏预留固定空白；提示和工具栏均悬浮显示。上拉时当前画面末端与下一章预览顶部衔接，松手取消后回到贴底状态。保留图片文件自身的边缘留白与系统手势安全区域。
