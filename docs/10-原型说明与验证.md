# 10 · HTML 原型说明与验证

## 1. 打开

直接打开 [prototype/index.html](../prototype/index.html)。所有 CSS、JavaScript 与 SVG 示意素材均在本地，无 CDN、外部字体或真实平台请求。

桌面浏览器默认显示手机评审框，可切换自适应；手机浏览器使用整屏。右侧评审入口属于原型工具，不属于正式 App。

## 2. 交互范围

- 三个纯图标底部入口；一级页面固定左侧标题、右侧搜索和设置。
- 探索/分类均为六平台横向 Tab，切换仍保留当前页面；分类分组随平台变化，点击进入分类结果。
- 探索在漫画源 Tab 下直接显示作品列表，无续读卡和最新/热门/推荐筛选；搜索页可通过六源 Tab 切换平台并保留关键词；空关键词仅显示最近搜索，不显示推荐书目。设置和结果页返回原页面。
- 漫画详情、目录、收藏/取消收藏、继续阅读。
- LTR/RTL 翻页、页码滑块、纵向连续、双击/按钮缩放、阅读设置。
- 书架、历史、下载演示队列、暂停/继续/取消、删除确认。
- 各来源不同登录入口、模拟登录/退出、网络模式/HTTP 代理表单、API/图片线路选择。
- 账号管理按平台分组，演示资料、折叠会话信息、重新登录和退出；网页登录独立页面演示自动获取/验证/返回，以及凭据缺失、验证失败和取消。模拟过程不读取当前浏览器的 Cookie/Token。
- 明暗主题、错误/空态/会话失效/配额演示、演示状态重置。
- 检查更新：当前版本、GitHub Releases 渠道、更新说明、下载暂停/继续/取消、校验结果及系统安装流程；可切换最新/网络失败/限流/暂无发布/不兼容状态。

## 3. 演示边界

作品与图片为原创示意数据，不是平台抓取结果。登录、线路检测、下载进度仅用于展示状态；表单明确提醒不输入真实凭据。密码、Cookie、API Key 和代理口令不持久化，也不发送网络请求。

localStorage 仅存演示收藏、阅读历史、平台浏览偏好、设置和下载状态；各平台滚动位置在本次打开期间保留。清理浏览器站点数据或重置演示可恢复默认。file:// 下 localStorage 若不可用，自动退回当前页面内存状态。

HTML 展示阅读交互意图；Android 的多指手势仲裁、大图分块、后台下载、Keystore、代理与 WebView 联调均尚未实现。原型不是 WebView 套壳 App 的实现方案。

更新页版本号、发布日期、包大小和 Release 内容均为示意；不请求 GitHub、不下载 APK、不申请真实安装权限，也不会伪造实际安装成功。尚未绑定 GitHub 发布仓库；真实发布与升级验证见[更新规范](11-应用更新与GitHub发布.md)。

## 4. 验证记录

最终浏览器检查结果与截图见 [验证结果](evidence/prototype-validation.md)。自动交互脚本为 [check-prototype.cjs](../tools/check-prototype.cjs)，可使用 Node.js + Playwright + Chrome 运行；脚本只访问本地原型。

评审顺序建议：探索切平台 → 分类切平台 → 分类结果 → 搜索 → 详情 → 收藏 → 阅读 → 退出后继续 → 下载 → 顶部设置 → 账号管理 → 网络线路 → 深色/异常状态。

## 设置页重设计

新设置页及全部选项见[设置规格](12-设置与偏好规格.md)。原型可保存开关/枚举值；关键词与语言过滤示意书目；明暗与纯黑立即生效；逐页双击/长按缩放与自动翻页可操作；下载演示队列遵守并行数；用户数据可导出为实际 JSON 文件、校验后预览合并；日志可导出示例文本。启动检查按本地时间模拟每日节流。

SAF 目录选择、真实缓存占用/清理、平台排序/签到/线路刷新、WebDAV 连接与同步仅是演示状态；没有外部请求。WebDAV 表单仅内存保存，不持久化或导出密码。音量键、常亮、高刷新率与实际预加载只保存偏好，留待 Android 实现。连续模式原型按页自动推进，缩放示例仅逐页模式支持。

新增设置交互验证脚本：[check-settings.cjs](../tools/check-settings.cjs)；报告：[设置验证](evidence/settings-validation.md)。

### 连续阅读手势补充

纵向模式支持鼠标按住拖拽、单指触屏拖动，以及到底后继续上拉、松开进入下一章。滚轮在底部继续向下滚动也能触发同一过渡；最后一章仅短暂显示紧凑悬浮提示。图片之间保持无间距、无页码。

验证脚本：`tools/check-reader-scroll.cjs`。结果见 [连续阅读手势验证](evidence/reader-scroll-validation.md)，效果见 [上拉换章](evidence/reader-pull-next.png) 与 [最后一章提示](evidence/reader-last-chapter.png)。这些仅为离线 HTML 原型的浏览器验证，尚未验证 Android 原生滚动物理效果及真机性能。
