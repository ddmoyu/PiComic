# 下载、离线与数据能力

2026-09-20 开发记录。D4 功能代码已实现；本地合同测试不能替代六平台真实账号、图片、实体设备和服务商验收。

## 已实现

- 独立 Room 下载库：稳定来源/作品/章节/账号键、逐页清单、持久状态、SHA-256/格式/尺寸校验；重启恢复任务，用户从下载管理继续。
- 1–6 个章节并行，默认 3；单来源最多 2 个任务、下载图片全局 2，JM 完整图重组与在线阅读共用 1 个许可，EH 共用额度停止门。
- 原图响应支持强 ETag 且 Range 校验通过时续传；不支持则重取该页。取消等待底层写入结束，已验证完成页保留；损坏页重新下载。
- 用户主动下载使用 dataSync 前台服务和暂停通知；WorkManager 只作延后恢复提示，不从开机广播启动长下载。系统超时停止服务并保留任务。
- 章节多选、暂停/继续/删除、删除失败保留状态；默认应用私有目录、SAF 持久授权目录、授权失效暂停。目录更改仅作用于新任务。
- 下载管理直接打开离线清单，不走平台登录或内容 API。保留实际章节/页面 ID 和阅读偏好，清缓存不影响已下载文件。
- 缓存真实占用，默认 500 MB 十进制配额；调整限额与清理等待正在使用的文件释放，继续由 Coil LRU 回收。
- GIF 动画解码；Android 9 及以上动画 WebP 解码。旧系统 AVIF 明确报告不支持，Hitomi 使用 WebP。
- 带版本的 JSON 备份合同、大小/结构/字段/重复与引用校验、未知来源保留、删除标记、逐项冲突选择；备份不含封面 URL、目录、平台凭据、WebDAV 凭据或来源端点。
- 收藏、历史、逐作品与可迁移偏好使用同一 Room 导入事务。偏好使用 Room 作为可迁移记录的权威数据，现有界面偏好文件保留为兼容投影，以保持与书架事务的一致性；不是原计划中的独立 DataStore 事务。
- WebDAV 独立加密凭据、HTTPS 目录探测、受限 XML 解析、条件写入能力试验、只读导入、ETag 合并和 412 重新预览；上传失败保留本地修改，远端读回一致才报告成功。

## 验证记录

- Android 16 下载/断点/缓存/内容导航专项：11 / 11 通过。
- Android 16 阅读全屏、离线入口、合成格式专项：4 / 4 通过。包括 JPEG、PNG、WebP、GIF、动画 WebP、AVIF；没有抓取平台漫画图片。
- Android 8.0 / API 26：下载队列、断点、存储、缓存、离线入口、格式、备份合同、数据库升级，共 16 / 16 通过。AVIF 拒绝路径通过；GIF 保留动画。
- 备份事务回滚、预览后数据变更与 WebDAV 合同专项已通过；系统目录授权、写入/删除/撤权在 API 26 的真实 DocumentsUI 通过独立测试。最新完整回归见 [23 号文档](23-首版功能与集成验证.md)。
