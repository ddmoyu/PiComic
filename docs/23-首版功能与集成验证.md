# 首版功能与集成验证

2026-09-20；开发版本 `0.3.0-alpha` / versionCode `8`，包名 `io.github.ddmoyu.picomic`，最低 Android 8.0 / API 26。

## 范围与结论

按 01、05、07、09、11、12 号文档的首版范围实现 D1–D5 的功能代码。多来源聚合搜索、完整平台收藏同步、双页/裁白边仍属原计划 P1，未混入本次首版交付。真实平台准入和正式发布的验收不能由本地测试代替，版本保留 alpha。

| 范围 | 当前实现 |
|---|---|
| 六来源 | 搜索、分类、详情、真实章节/页面标识及分页；各来源认证、权限和地址边界 |
| 网络与账号 | 跟随系统或 HTTP 代理、无失败直连回退、受控 WebView、加密会话、退出和迟到回调隔离 |
| 阅读 | LTR/RTL/连续、长图分块与缩放、页码/偏移恢复、音量键、自动翻页、显示与逐作品偏好 |
| 书架 | 本地收藏/撤销、历史/删除、搜索记录和数据库迁移 |
| 下载 | 持久队列、暂停/继续、服务与通知、逐页校验、内部/SAF 目录、离线阅读 |
| 数据 | 版本化备份、字段与容量校验、未知来源保留、删除标记、预览/冲突选择、原子导入 |
| WebDAV | 独立凭据、连接/条件写入能力探测、ETag、412 重新预览、只读导入和待同步状态 |
| 设置 | 关键词/语言、来源排序与线路、签到、头像/头像框、EH 配置、主题/刷新率、缓存与日志 |
| 更新 | 稳定 Release/清单校验、304/限流、ABI/系统筛选、下载恢复、包名/签名/摘要校验、安装权限与系统安装 |

偏好实现采用 Room 权威记录和现有 SharedPreferences 界面投影，实现与书架的同一导入事务；相对于 12 号设计中的 DataStore 建议，这是有意保留的实现选择。

Lint 没有错误 baseline。剩余警告包括固定依赖/目标 SDK 的升级建议、KTX/Compose 风格建议、持久偏好写入、协议要求的 JM AES/ECB 和应用级单例 Context 提示；单例工厂均传入 applicationContext，账号存储仍为 Keystore AES-GCM。

已完成 API 26 系统 DocumentsUI 的独立 SAF 测试：选择专用 `Documents/PiComic-SAF-Fixture`，写入并读回校验合成 PNG，删除任务而保留无关文件，撤销持久授权后拒绝继续写入。可用 `tools/check-saf.ps1` 配合显式 `-e saf 1` 仪器用例重复验证，默认针对英文 API 26 测试模拟器。该结果不代表 SD 卡或其他云盘提供方已经验收。

本轮修复包括：Coil/ZoomImage 状态更新移至 Compose 副作用以避免组合期间并发修改；下载库 1→2 保留任务/页序并增加 EH 副标题；备份保留来源长标题/换行；更新下载重试遵守服务端冷却；JM 发布域名更新保留当前选择和已验证候选。

图片请求尺寸变化时创建新的 Coil painter，避免在组合过程中同步重启已有 painter；长图测试反复切换请求尺寸并重新命中缓存，仍验证全分辨率分块可用。API 26 全屏检查采用原生隐藏标志，截图确认铺满窗口；旧版 Insets 兼容接口会保留稳定边距。其 WebView 69 不支持自定义代理，验证了明确拒绝和系统代理提示；API 36 则验证 WebView/API 实际经过同一测试代理。

360 dp、1.6 倍字号下 WebDAV 和更新操作可滚动到达，按钮按空间换行；大字体截图（历史截图已清理）。R8 包在 API 26、36 均启动正常，默认真实来源入口且无演示目录；API 26 同版本 Debug→R8 覆盖后保留 2 条原有合成收藏，进程重启仍可读，更新页按未配置渠道禁用操作。Release 截图（历史截图已清理）。API 36 的 600 dp（历史截图已清理） / 800 dp（历史截图已清理） 入口布局已检查，模拟器密度已恢复。正式旧版本升级和真实平台 R8 链路仍属外部验收。

## 发布工具与依赖声明

- `tools/prepare-release.ps1` 从签名 APK 读回包名/版本/minSdk/ABI/大小/SHA-256，验证预期证书及 v2 签名，再生成 `picomic-update.json` 和验证报告。默认拒绝开发版本；不执行上传。
- `tools/runtime-inventory.init.gradle` 导出实际 Release 依赖，`tools/build-license-notices.py` 从 POM 和包内声明汇总许可。179 个运行时/脱糖组件已纳入随 APK 打包的清单；详见 `THIRD_PARTY_NOTICES.md`。
- 本地 Release 使用显式 `localReleaseSigning=true` 的开发证书，只用于安装验证；普通 Release 未签名。
- `releaseOwner/releaseRepo` 默认空，更新页明确显示未配置。私有源码仓库不作匿名安装包分发，不在 APK 内置 GitHub 令牌。

## 外部验收缺口

1. 六个平台的有效真实账号及完整来源准入：首次/失效/重新登录、真实首中末图片、真实下载和离线。匿名元数据与协议夹具结果见 17、19、20 号文档。
2. 真实 WebDAV 服务商与两台设备：不同提供方的条件写入、并发更改、掉线恢复。
3. 实体手机：内存/耗电/后台限制、系统 VPN、刷新率、外置 SD 卡、磁盘不足和真实重启恢复。
4. 正式签名和公开 Releases 分发端：远端资产读回、安装权限拒绝/撤销、安装取消/失败/成功、正式旧版本覆盖保留数据。
