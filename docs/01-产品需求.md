# 01 · 产品需求

版本 v0.1 · 更新：2026-09-18 · 状态：待产品/原型评审

## 1. 产品定位

PiComic 是面向 Android 手机的多来源漫画阅读器。用户在 App 内选择来源、浏览或搜索作品、进入详情并阅读；书架、历史和下载在本地保存。无需配置插件，也不要求注册 PiComic 账号。

主要价值：六个固定来源入口清楚，阅读顺畅，会话失效和线路异常可以理解、可以恢复。平台账号属于对应平台，不合并为 PiComic 统一账号。

## 2. 用户任务

| 任务 | 成功标准 |
|---|---|
| 找到漫画 | 选择来源或搜索后可进入正确作品，来源名称始终可辨识 |
| 开始阅读 | 详情页主按钮直接打开第一章或上次位置 |
| 连续阅读 | 图片失败仅影响对应页，可重试；翻页不被后台下载阻塞 |
| 下次继续 | 重启后恢复章节、页码和连续阅读的页内位置 |
| 离线阅读 | 已下载章节在飞行模式可打开，缓存清理不删除下载 |
| 处理登录/线路问题 | 指出是登录、权限、验证、网络或额度问题，提供对应入口 |

## 3. 功能范围与优先级

P0 是 v1.0 必须完成的交付范围；P1 在 P0 稳定后安排，不把产品建议当作已确认需求。

| 编号 | 功能 | 优先级 | 规则 |
|---|---|---|---|
| SRC-01 | 六组内置来源 | P0 | EH/EX 为同组中的两个访问模式；每组独立启用和诊断 |
| EXP-01 | 探索/更新/排行 | P0 | 按平台 Tab 浏览；根据平台能力显示栏目，无排行来源隐藏排行入口 |
| CAT-01 | 分类与标签 | P0 | 按平台 Tab 展示各自分类；保留来源差异，不伪造统一分类结果 |
| SEA-01 | 可切换漫画源的单源搜索 | P0 | 六源 Tab、切源保留关键词；搜索历史、分页、排序、空结果、错误重试；不显示推荐书目 |
| SEA-02 | 多来源聚合搜索 | P1 | 按来源分组；不按同名直接合并作品 |
| DET-01 | 详情/目录 | P0 | 标题、封面、标签、描述、章节或单册、已读位置 |
| RDR-01 | 三种阅读模式 | P0 | 左到右、右到左、纵向连续；逐作品记忆 |
| RDR-02 | 阅读辅助 | P0 | 双击/双指缩放、跳页、目录、亮度、背景、方向设置 |
| LIB-01 | 本地书架与历史 | P0 | 本地收藏不要求平台登录，历史按稳定作品 ID 存储 |
| DL-01 | 下载管理 | P0 | 章节选择、暂停、继续、失败重试、取消、删除、离线读 |
| AUTH-01 | 平台登录/授权 | P0 | 账号密码、WebView 登录自动获取并验证会话、Cookie、API Key 按平台分别提供 |
| NET-01 | 网络与线路 | P0 | 系统网络默认；自定义 HTTP 代理；来源 API/图片线路独立 |
| SET-01 | 设置/数据管理 | P0 | 分组设置；内容筛选、来源参数、阅读/外观、日志、下载/缓存、用户数据、代理与关于 |
| UPD-01 | 检查更新 | P0 | GitHub Releases 稳定版；手动检查、可选启动检查、更新说明、APK 下载校验、系统安装确认 |
| FAV-02 | 平台收藏同步 | P1 | 与本地收藏分开；失败不撤销本地收藏 |
| RDR-03 | 双页/裁白边 | P1 | 基础阅读体验通过后再加入 |
| SYN-01 | WebDAV 用户数据同步 | P0 | 手动同步书架、进度与偏好，先预览差异及冲突，不上传凭据 |

首版不提供：动态扩展/脚本管理、内置 VPN、漫画发布、评论发送、社交系统、桌面/iOS 客户端、平板专属 UI、AI 超分辨率。

## 4. 基础体验规则

- 首次启动进入探索页；默认来源建议为 picacg。需要登录时显示来源登录卡，其他来源和本地内容仍可使用。
- 探索、分类通过横向平台 Tab 直接切换；顶部固定页面标题及搜索/设置操作，底部导航只显示图标并提供无障碍名称。
- 每来源仅一个活动账号是首版基线；切换账号会隔离其私有缓存与网络任务，但保留本地书架/历史。
- 来源选择、账号管理、网络线路分开。普通阅读页面不出现签名、解析器版本等内部实现字段。
- 无章节作品归一为“全册”，保留来源真实页序。分页方向设置不改变实际页码含义。
- 无网时提供已下载内容入口；登录失效时保存当前阅读位置。
- “设置 → 更新”提供检查更新入口；使用应用当前网络策略获取 GitHub Releases，不要求用户登录 GitHub。仅用户发起下载和安装，检查失败不显示已是最新。
- 原型暂用虚构作品展示布局，不代表任何平台的实际内容或可用性。

## 5. 非功能要求

| 项目 | 建议基线 | 验证方法 |
|---|---|---|
| 最低系统 | Android 8.0 / API 26，建工程时以依赖兼容矩阵确认 | 最低系统模拟器运行 |
| 主要屏幕 | 360–430 dp 手机宽度 | 360/390/430 dp 与大字体 |
| 基本兼容 | 600/800 dp 平板窗口、横屏、分屏可操作 | 全流程无遮挡、无丢失进度 |
| 即时反馈 | 点击后 100 ms 内有视觉响应；长请求有加载/取消 | 本地交互与限速网络分开测量 |
| 流畅度 | 参考 60 Hz、6 GB RAM 真机；连续阅读不持续掉帧 | Macrobenchmark/JankStats 后续实测 |
| 资源 | 有界图片内存、磁盘配额和平台并发；长图不 OOM | 100 页章节/极端长图/后台恢复 |
| 隐私 | 密码、Token、Cookie、API Key 不写日志或普通备份 | 日志与备份检查 |

网络耗时、平台限制不承诺固定加载秒数。性能数字是验收目标，不是当前测试结果。

## 6. 待评审决策

当前建议默认即可推进原型：蓝色 Material 3、底部三入口、Android 8+、当前来源搜索、本地收藏优先、密码记忆默认关闭。更新发布渠道已确定为 GitHub Releases；后续确认仓库 owner/repo、应用包名、正式签名、最低系统与是否加入 P1 功能。以上不阻塞本轮文档与原型交付。
