# 08 · 数据模型与存储

## 1. 持久数据

| 表/对象 | 主键/重要字段 | 约束 |
|---|---|---|
| SourceSettings | sourceId, enabled, siteMode, preferredApi, preferredImage, profileVersion | 不存密码/Token |
| Comic | sourceId + comicId, title, coverRef, author, tags, description, updatedAt | 来源内稳定 ID；同名不合并 |
| Chapter | sourceId + comicId + chapterId, order, title, pageCount | 全册使用稳定 whole ID |
| PageManifest | chapterKey + pageId, order, width, height, resolveRef, transformMeta | 页序独立于地址；大清单分页存取 |
| Favorite | comicKey, folderId, addedAt | 本地收藏，不依赖远端登录 |
| ReadingProgress | comicKey, chapterId, pageId, indexFallback, offsetRatio, mode, updatedAt | 更新节流；退出/跳章强制保存 |
| DownloadTask | taskId, chapterKey, accountPartition, state, donePages, error, policy | 唯一工作键，避免重复章节任务 |
| DownloadPage | taskId + pageId, relativePath, format, size, checksum, state | 完成文件才记 Complete |
| SearchHistory | sourceId + normalizedQuery, usedAt | 来源隔离，保留原始显示文本 |
| SessionDescriptor | sourceId + accountId, authMethod, status, validatedAt, credentialRef, generation | 只存凭据引用，不存明文 |
| AccountProfile | sourceId + accountId, displayName?, level?, experience?, bio? | 可选平台资料；缺失时 UI 隐藏，不包含 Token |
| UpdateCache | repository, releaseId, etag, checkedAt, validatedMetadata | 不存 GitHub PAT；304 必须对应有效缓存 |
| AppUpdateTask | assetId, releaseId, versionCode, size, sha256, partialPath, state | 与漫画下载分离；安装器返回不等于升级成功 |

Room 外键和事务保持书架/章节/下载引用一致。删缓存不删收藏，退出账号不删本地历史，删除下载不把作品从书架移除。

WebView 登录的 `SessionCandidate` 只在登录尝试内短暂存在，包含来源、获取方式及凭据；未验证时不写入正式 SessionDescriptor。验证成功、generation 核对和密文提交完成后才更新账号状态；取消/失败销毁候选。HTML 原型只保存模拟登录方式与验证时间，绝不读取真实 Cookie/Token。

## 2. 会话与缓存分区

账号标识用不可逆本地分区 ID，不将账号密码拼进目录名或缓存键。公共元数据可按 sourceId 缓存，账号私有结果和访问受限图片按 source/account 分区。退出后旧请求不得把私有结果写入新账号分区。

Cookie 与账号密文放应用私有目录，由 Keystore 密钥保护，排除自动备份。密钥丢失/设备迁移导致不可解密时清理失效会话并要求重新登录，不能崩溃。DataStore 保存主题、阅读偏好、非敏感代理参数与网络 profile ID。

## 3. 文件目录

```text
files/downloads/<source>/<comic>/<chapter>/      持久下载
files/sessions/                                凭据密文，禁止普通备份
files/updates/                                 更新 APK 与断点，升级后清理
cache/pages/<partition>/                       已处理图片缓存
cache/raw/                                     受配额约束的临时原图
cache/partial/                                 在途文件，恢复/清理策略明确
```

文件名使用稳定内部 ID/哈希，不能将远端标题、URL 路径直接当本地路径。首版支持通过 Storage Access Framework 选择下载目录；默认内部目录并明确卸载会清除。使用持久 URI 授权；目录变更只用于新任务，旧任务继续引用原目录。授权丢失时暂停任务，不自动迁移或删除。

## 4. 阅读进度

以真实 pageId 为主、index 为兜底。长图记录当前位置相对原图高度的归一化比例，不把屏幕像素当跨设备永久位置。章节更新时 pageId 无法匹配，保留历史并提示从最近可匹配页开始；不可把第 12 页错误对应到不同章节。

HTML 原型用 localStorage 保存演示收藏、历史和设置，服务于评审；不会被视为 Android 数据层设计的替代品。

## 5. 备份/恢复

首版提供带 schemaVersion 的 JSON 备份：书架、历史、阅读偏好、来源启用状态。默认不包含 Cookie、密码、API Key、代理口令、签名材料或下载图片。

导入先验证版本、大小与字段，在临时结构预览合并数量，再事务写入。按稳定作品键去重；历史按更新时间合并；未知来源记录保留但不激活；失败回滚。导入文件不能修改可信 API 主机白名单。

Room schema 导出纳入版本控制，每次升级测试迁移。禁止正式版本靠 destructive migration 自动清空书架或下载记录。

## 偏好与 WebDAV 同步数据

AppPreferences 保存筛选、阅读、外观、下载并行/缓存上限及启动检查；SourcePreferences 按 sourceId 保存平台参数，DownloadLocation 保存设备本地 URI 授权引用。SyncState 保存服务端资源路径、ETag、设备 ID、修订号、最后成功时间及待同步变更；删除记录保留 tombstone。WebDAV 账户凭据独立加密并排除备份。

WebDAV 纳入 P0，首版手动触发，差异预览和冲突选择后同步；条件 PUT 防止远端并发覆盖。来源端点/敏感设置与本机目录不随普通用户数据迁移。详见[设置规格第 6 节](12-设置与偏好规格.md#6-webdav)。
