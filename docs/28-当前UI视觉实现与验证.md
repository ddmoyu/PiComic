# 当前 UI 视觉实现与验证

2026-09-22，用户确认本轮重新截图制作的 HTML 后，将方案移植到当前 Android Compose 界面。

## 已实现

- 探索、收藏、历史、下载共用紧凑作品行：100 dp 封面、清晰的标题/作者/标签/页数层级、细分隔线。探索的来源 Tab 已标明来源，行内仅保留 ID 和语言；混合来源的书架列表保留来源名称。
- 分类保留原版接近的浅底圆角标签；可见高度 32 dp，Material 组件提供至少 48 dp 触摸区域，横向间距 8 dp。内容和顺序不变。
- 详情刷新位于“作品详情”顶栏右侧，滚动目录时仍可操作；加载期间禁用。仍强制重新请求详情，刷新不清除收藏、阅读位置或下载。信息字段统一为“标签”，章节继续使用单行虚拟列表。
- 搜索结果保留封面网格，仅封面、标题和作者；设置保留四组原有入口，统一分组分隔、摘要、图标及间距；阅读器仅改善工具栏表面对比度，图片继续零间距。
- 浅色/深色使用统一语义配色。纯黑、跟随系统主题及阅读画布偏好沿用原逻辑。
- 全应用图标切换为官方 Phosphor 2.1.1 Regular；收藏选中使用同库填充心形。共 25 个矢量，官方路径原样转换，不手绘。默认图标 24 dp、图标按钮 48 dp；中文操作描述与收藏选中语义保留。原 SVG、版本和完整性记录、MIT 许可及离线生成工具一同保存，APK 内包含许可。见 [图标说明](../third_party/phosphor-icons/README.md)。

未添加产品功能或额外入口。探索仍无续读卡片，即使已有阅读历史。
