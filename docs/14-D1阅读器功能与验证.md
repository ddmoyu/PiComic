# 14 · D1 阅读器功能与验证

更新：2026-09-20；版本 `0.2.0-alpha`，versionCode 4。

本轮完成 D1 的阅读器子阶段，将原有界面设置接入实际行为。漫画数据仍来自原创示意目录，不代表六平台已联网。D1 的代理 / WebView 和六来源协议联调继续保持待开发状态。

## 已实现行为

| 能力 | 行为 |
|---|---|
| 全屏 | 保留默认全屏，轻点显示 / 隐藏操作栏；图片不因菜单显隐改变尺寸 |
| 图片 | 接入 Coil 3.4.0、ZoomImage 1.5.0；逐页阅读支持分块解码、多指缩放、双击缩放、拖动平移；失败提供重试 |
| 连续缩放 | 对整个可见阅读区统一缩放，避免每幅漫画分别抢夺滚动；放大时拖动平移，复原后继续列表阅读 |
| 长按缩放 | 设置开启后，按系统长按阈值临时放大；松开 / 取消恢复之前的比例与平移位置 |
| 缩放按钮 | 工具栏提供放大 / 还原，即使关闭双击，也可手动缩放 |
| 音量键 | 仅前台阅读且启用时接管；音量减向后、音量加向前；连续模式推进约 88% 视口，逐页模式递增 / 递减逻辑页码；RTL 页码仍按阅读顺序递增 |
| 自动翻页 | 工具栏播放按钮手动启动；按设置间隔推进；触摸、拖动、面板、放大期间暂停，恢复后重新计时；章末停止，不自动换章；退后台 / 退出停止 |
| 常亮 | 开关真实控制前台阅读窗口，退后台或退出同步释放，不申请后台唤醒锁 |
| 预加载 | 沿逻辑页序前向 1–10 张、后向至多 1 张；预取并发 2；快速跳页 / 切章 / 退后台取消旧窗口任务；当前仍加载本地素材 |
| 进度 | Room 保存来源、作品、章节、页码、页内比例、阅读模式和更新时间；滚动约 350 ms 采样，退出 / 后台补存；按来源隔离，重开数据库可恢复 |
| 保持兼容 | 原有 Tab 横滑、全屏、工具栏、目录、上下章、连续零间距及手动上拉换章继续保留 |

## 工程

- `reader/ReaderImages.kt`：图像边界、加载请求、Coil / ZoomImage 组件。当前 `ReaderPage` 使用独立页面键，本地资源由示意目录提供；未来真实来源通过 PageRepository 接入，不直接把远端裸 URL 当持久身份。
- `reader/ReaderDeviceEffects.kt`：阅读生命周期、音量键回调和常亮。暂停时直接释放，不能依赖退后台后暂停的 Compose 帧。
- `reader/ReaderMath.kt`：预加载窗口、页内比例与计时范围。
- `data/ReadingDatabase.kt`：Room v1、DAO、应用生命周期内的串行写入队列。数据库 / 文件工作不在 UI 线程；没有 destructive migration。Schema 位于 `app/schemas/`。
- 基础偏好、收藏和搜索历史继续使用已有 SharedPreferences，不丢弃原设置；本轮只迁入新增阅读进度。示意账号与演示下载仍不持久化为真实业务状态。
- Coil / ZoomImage 版本选择与当前 Kotlin 2.3.21 编译组合验证，不以最新版本为目标。KSP 2.3.9、Room 2.8.5 已通过构建。许可见根目录第三方说明。

## 验证与边界

验证结果及安装包校验见 [Android 验证记录](evidence/android/validation.md)。自动化覆盖真实窗口标记、系统按键注入、进度页内比例恢复、源隔离、数据库关闭重开、自动翻页、全屏和既有导航流程。

长图测试在模拟器现场生成 **640 × 16,000** 原创测试图，检查逐页组件的 subsampling ready、tile grid 与放大状态；没有下载平台作品。该结果不代表所有格式或低内存真机均已通过。连续模式真实超长图的切片 / 可见区域解码、AVIF / GIF 格式矩阵、100+ 页及弱网压力仍属 D1 后续验证项，不能用本地普通素材替代。

下一子阶段按计划接入统一网络策略、受控 WebView、加密会话及六源协议验证；之后选择实测可用的 picacg 或 JM，完成不依赖示意数据的搜索 → 详情 → 阅读闭环。GitHub 仓库、正式签名、真实账号和实体手机验收仍未完成。
