# 12 · 设置与偏好规格

更新：2026-09-18。范围来自本轮设置清单及漫画源参考图。功能纳入 v1.0；下表默认值是建议基线，不代表平台当前支持或已完成 Android 实现。

## 1. 页面与归类

设置首页只展示分组入口、摘要和右箭头；具体开关进入二级页面。标题与返回按钮固定，内容独立滚动，二级页面不显示底部导航。继承原型的蓝色 Material 3 视觉，避免把几十个设置堆在首页。

| 首页分组 | 入口 | 二级页面内容 |
|---|---|---|
| 内容与来源 | 账号管理 | 资料、登录/重新登录、WebView 会话获取、退出 |
| 内容与来源 | 漫画源 | 六平台横向 Tab、平台专属参数 |
| 内容与来源 | 内容筛选 | 关键词屏蔽、语言多选 |
| 阅读体验 | 阅读 | 翻页、显示与加载、缩放手势 |
| 阅读体验 | 外观 | 跟随系统、浅色、深色、纯黑、高刷新率 |
| APP | 更新 | 手动检查、启动时检查更新、GitHub Releases 流程 |
| APP | 数据与同步 | 下载目录/并行、缓存、导入导出、WebDAV |
| APP | 日志 | 运行记录、导出 |
| 网络与关于 | 设置代理 | 跟随系统或自定义 HTTP 代理 |
| 网络与关于 | 关于 PiComic | Logo、介绍、项目地址、问题反馈 |

行结构为“标题 + 可选解释 + 当前值/开关/箭头”。切换类用 Material 3 Switch；互斥值用单选面板；语言用多选；高影响操作先确认。点击区域不小于 48 dp，长副标题换行，不与右侧控件重叠。平台 Tab 可横滑，切平台和返回保留滚动位置。首屏摘要随偏好更新。

### 与书架的边界

取消独立“我的”页面，设置成为账号与应用配置的统一页面。收藏、阅读历史、下载任务全部归入书架的对应 Tab，不在设置再建入口。“数据与同步”的下载部分命名为“下载偏好”，只控制目录和并行；缓存、备份、同步仍在这里。关于页承载 Logo/介绍，不另建个人资料占位页。

## 2. 内容筛选

| 设置 | 默认 | 行为 |
|---|---|---|
| 关键词屏蔽 | 空列表 | 增加、删除；标题/作者/标签包含任意关键词即隐藏 |
| 语言筛选 | 不限 | Chinese、English、Japanese 可多选；全不选等于不限 |
| 保留未标注语言的作品 | 开 | 选语言后，来源没有语言字段的作品是否保留 |

屏蔽词采用 NFKC 归一化和不区分大小写的字面包含匹配，不执行正则或脚本；最多 100 项，每项 80 字符，去掉空白并去重。原型按示意作品语言字段过滤。正式适配器把语言标签规范化为 `zh/en/ja/unknown`，不得凭标题猜语言；服务端支持筛选时先传参，再统一过滤结果。

作用于探索、搜索、分类结果，不删除收藏、历史、下载或已有数据。被过滤后列表空显示空态；正式分页保留服务端游标，允许继续加载，不能把“本页过滤为空”误当全部结束。修改偏好取消过时查询，防止旧结果覆盖。

## 3. 漫画源

漫画源页使用横向 Tab，不用下拉；配置页选择的平台不改变探索当前平台。以下字段与参考图对应，真实选项由内置适配器的能力和有效候选地址提供；原型分流编号不代表可用域名。

| 平台 | 设置 | 建议默认与行为 |
|---|---|---|
| picacg | 搜索及分类排序模式 | 新到旧；另有旧到新、最多喜欢，具体枚举待接口验证 |
| picacg | 收藏夹漫画排序模式 | 新到旧；指平台收藏，区别于本地书架 |
| picacg | 显示头像框 | 开；平台资料没有头像框时使用普通头像 |
| picacg | 自动打卡 | 关；有效会话、前台启动、当日未成功时执行 |
| E-Hentai | 画廊站点 | e-hentai.org / exhentai.org；EX 权限单独验证 |
| E-Hentai | 优先加载原图 | 关；失败提供普通图回退，额度不足暂停预取 |
| E-Hentai | 忽略警告 | 关；仅处理站内可跳过的内容提示，不绕过认证、证书错误或权限校验 |
| E-Hentai | 优先显示副标题 | 关；已下载画廊优先副标题，缺失则使用主标题 |
| E-Hentai | 配置文件 | 导入/编辑经校验的平台设置；不执行文件中的代码 |
| nhentai | 删除 Cookie | 确认后清理网页会话及相关任务；独立 API Key 保留 |
| 禁漫天堂 | 自动选择域名 | 开；登录前从可信候选选择可用 API 线路 |
| 禁漫天堂 | API 域名、图片分流 | 各自独立；自动模式中手选作为偏好，失败允许候选回退 |
| 禁漫天堂 | 收藏夹漫画排序模式 | 最新收藏；可选最早收藏、最近更新，待平台验证 |
| 禁漫天堂 | 更新 API 域名 | 获取并校验可信配置，失败保持旧地址，正在使用的请求保持一致 |
| 禁漫天堂 | 自动签到、测试签到 | 关；开启后提供一次测试，成功后当日去重 |
| Hitomi | CDN 域名 | 参考图 gold-usergeneratedcontent.net；待实测 |
| 绅士漫画 | 域名 | 参考图 www.wnacg.com；待实测 |

域名输入仅接受合法主机名，不允许混入协议、路径或账号。API 与图片 Cookie/Token 的发送范围仍由来源认证策略约束：编辑域名不等于授权把旧凭据发送到任意主机。新主机需验证来源归属；站点变化需重新验证会话。

自动打卡/签到以来源、账号和平台日历日期去重，并保留成功时间；会话失效停止，失败有限重试，用户关闭后取消待执行任务。没有已验证接口的适配器显示暂不可用及原因，不伪造成功。仅启用已登录账号；不用系统后台定时器保证精确午夜签到。平台收藏排序配置纳入设置，完整平台收藏同步仍按 P1 范围安排。

EH 配置文件原型只接受 `site/original/ignoreWarning/subtitle` 的严格 JSON；正式配置另设 schemaVersion，大小限制、字段白名单和预览，账号 Cookie 不混入配置文件。

## 4. 阅读与外观

| 设置 | 默认/范围 | 生效规则 |
|---|---|---|
| 阅读模式 | 从左到右；从右到左；纵向连续 | 立即生效，保留稳定页码/页内位置 |
| 音量键翻页 | 关 | 开启且阅读器前台时：音量减下一页、音量加上一页；退出恢复系统行为 |
| 自动翻页时间间隔 | 5 秒；2/3/5/10/15/30/60 秒 | 阅读器播放按钮手动启动；修改间隔重置倒计时 |
| 保持屏幕常亮 | 开 | 仅前台阅读页面持有，离开、后台或销毁时释放 |
| 图片预加载 | 3 张；完整 1–10 张 | 沿页序前取，少量后向缓存独立；不等于 10 个并发解码任务 |
| 双击缩放 | 开 | 双击放大，再次恢复；关闭后按钮缩放仍可用 |
| 长按缩放 | 关 | 按住约 450 ms 临时放大，松开/取消恢复；移动阈值避免抢占拖动 |
| 主题模式 | 跟随系统；可选浅色模式、深色模式 | 默认响应系统主题变化；手动选择后固定采用所选主题并持久化，旧版手动深浅色选择保留 |
| 纯黑色模式 | 关 | 仅深色下启用；浅色时置灰但保留偏好 |
| 高刷新率模式 | 关 | 默认跟随系统；开启后请求设备支持的较高刷新率 |

阅读画布的深灰、纯黑、米白背景只在阅读区域生效；进入、退出阅读以及页面转场不修改全局主题。阅读工具栏和设置面板沿用当前主题。选择“跟随系统”后，纯黑色模式开关根据系统当前深浅色状态启用或置灰，保留已保存的偏好。主题模式参与备份与同步。

自动翻页不自动开启下一章；本章结束停止。翻页失败停止并保留进度；后台、退出阅读停止。打开面板、放大、长按或正在拖动时暂停计时，恢复交互后重新计时；手动跳页亦重新计时。RTL 下一页依然递增逻辑页码。连续模式正式版按视口推进，长图不能直接跳过尚未读完区域；原型按示意页推进。

原生阅读页用 `FLAG_KEEP_SCREEN_ON`，不为普通阅读申请后台 CPU 唤醒锁；Activity 离开前台后无需维持屏幕。[Android 屏幕常亮](https://developer.android.com/develop/background-work/background-tasks/awake/screen-on)

高刷新率使用窗口/显示模式能力并处理生命周期；不承诺强制 120 Hz。系统和省电策略可覆盖应用请求，UI 保持“优先”语义。[Android 帧率策略](https://developer.android.com/media/optimize/performance/frame-rate)

## 5. 数据、缓存与日志

| 设置 | 建议基线 |
|---|---|
| 设置下载目录 | 默认应用私有目录；系统目录选择器选择 Documents/SD 卡的可授权目录 |
| 下载并行 | 3 个章节任务，可选 1–6；来源限流、图片请求和处理并发另有限制 |
| 缓存大小限制 | 默认 500 MB，可选 250/500/1000/2000 MB |
| 缓存占用 | 显示实际占用/上限；222.18 MB / 500 MB 仅是原型样例 |
| 清除缓存 | 确认后清理临时图片，不删除已下载漫画、书架、历史、账号或更新 APK |
| 导入、导出配置与账号 | 密码加密的 `.picomic`；导入兼容旧版 JSON；预览合并数据、逐来源选择账号 |
| 日志 | 显示时间、级别、摘要；导出前脱敏，不记录正文、令牌、Cookie、密码及带查询参数 URL |

正式下载目录通过 `ACTION_OPEN_DOCUMENT_TREE` 和持久 URI 授权访问；Android 11+ 对根目录、Download 根目录等有访问限制，不能把路径文本框当作权限。授权被撤销时暂停任务并重新选择。目录变化只用于新任务，旧文件保留原 URI；迁移需要单独动作，不静默移动或删除。[Android SAF](https://developer.android.com/training/data-storage/shared/documents-files)

降低并行数后已有任务完成或停在安全页边界，不启动超额任务。降低缓存额度异步回收 LRU；当前打开文件使用引用保护，清理过程中数据页显示进行中，失败可重试。缓存容量统一用十进制 MB，并与下载文件/更新包分开计数。

普通 JSON/WebDAV 数据包含本地书架、历史、内容与阅读偏好，排除账号凭据。新版手动导出使用 8–128 位备份密码加密，默认包含已保存的平台会话、记住的账号密码，可取消包含账号；文件上限 12 MB。导入先预览，已有本机账号默认不勾选替换，导入会话需重新验证。WebDAV 密码、代理口令、设备目录、下载图片、任意远端地址和设备密钥始终排除。详见 [加密配置与账号备份](25-加密配置与账号备份.md)。HTML 原型仍为演示 JSON，不代表 Android 加密格式。

## 6. WebDAV

WebDAV 已由本轮需求纳入 P0。入口“设置 → 数据与同步 → 数据同步 WebDAV”；包含 HTTPS 服务器地址、用户名、密码/应用密码、测试连接、预览同步及冲突选择。原型不连接真实服务器，仅演示流程。

首版采用用户主动同步，跨设备合并书架和阅读进度、同步指定偏好，不上传漫画文件、平台账号及目录授权。采用独立 `WebDavCredentialStore`，密码由 Android Keystore 保护，不写普通 DataStore、日志或备份。请求遵循应用网络策略，但不携带任一漫画源凭据。

实现合同：

1. 测试目标目录权限，使用 `PROPFIND` 的有限深度；401/403、证书错误、404、超时和只读目录分别反馈。不自动创建用户未确认的父目录。
2. 读取带 schemaVersion 的清单、设备 ID、修订号及 ETag，校验长度与字段，在临时空间计算差异。
3. 书架按来源/作品稳定键合并；删除用 tombstone，不能因并集而让删除项复活。阅读记录同时修改时展示冲突选择，不以页码更大直接胜出。
4. 用户确认后提交本地 Room 事务；上传使用带 `If-Match` 的条件 PUT，新建资源用 `If-None-Match: *`。412 重新取版本并重新预览，不强行覆盖。
5. 清单单文件保持服务端写入原子性；不支持可靠条件写入的服务端禁用上传，提供只读导入。断网保留本地变更与待同步标记，不显示成功。
6. 服务器配置改变后必须重新测试。测试成功不等于已同步；密码修改或授权失败立即失效连接状态。

PROPFIND、资源属性及条件请求以 WebDAV/HTTP 规范和服务端实际行为为依据；兼容性测试覆盖不同服务商，不能只测一个成功服务端。[RFC 4918](https://www.rfc-editor.org/info/rfc4918/)

## 7. 更新、网络与关于

“更新”保留[GitHub Releases 更新合同](11-应用更新与GitHub发布.md)，新增“启动时检查更新”，默认关闭。开启后前台冷启动且距上次自动检查超过 24 小时才尝试；有新版本只提示，可稍后查看，不自动下载/安装。手动检查不受每日间隔限制，但仍遵守服务端限流。阅读过程中不弹阻塞对话框。

设置代理保留跟随系统网络/VPN及自定义 HTTP 代理，默认跟随系统。网页登录、API、图片、下载、更新和 WebDAV 各使用正确的客户端及凭据边界，详情见[网络与会话](06-网络登录与会话.md)。

关于页展示 Logo、名称、介绍、项目地址与问题反馈；当前版本、更新渠道、检查时间、更新说明及升级操作只在更新页显示。正式版项目首页指向自己的 GitHub 仓库，反馈指向同仓库 Issues；未配置时解释原因，不能跳转到竞品或虚构地址。

更新页不重复展示 Logo、品牌标语或应用介绍，顶部为紧凑版本/渠道卡。关于页不再显示另一套原型版本号或技术栈说明。更新页的“查看 GitHub Release”指向具体版本的发布说明，关于页的“项目地址”指向仓库首页，两者目的不同，保留各自入口。

## 8. 开发与验收

偏好保存在类型化 DataStore，通过 Flow 驱动 Compose；本地记录在 Room，敏感信息独立加密。增加 `ContentFilter`、`ReaderPreferences`、`SourcePreferences`、`DataTransferService`、`WebDavSyncService`；内置来源声明对应能力，没有通用脚本执行接口。

| 验收组 | 必测条件 |
|---|---|
| 设置导航 | 360 dp 窄屏、字体放大、横屏、深色；长标题不遮挡开关；返回保留滚动 |
| 内容 | 中文/英文关键词、大小写与全角、空列表、多语言/未知语言、全过滤后继续分页、书架不被删 |
| 来源 | 六 Tab 隔离；EH/EX 权限、原图回退；Cookie 与 Key 隔离；地址失败保留旧配置；签到按账号日期去重 |
| 阅读 | 1–10 张预加载、低内存；音量键拦截/释放；常亮释放；缩放与拖动仲裁；自动翻页暂停与章末停止 |
| 数据 | URI 撤权、磁盘满、并行调低、缓存正在读；错误密码/损坏/超限/未来版本备份；事务回滚；秘密不进入明文导出或 WebDAV |
| WebDAV | 离线/401/403/只读/412、两设备并改、删除冲突、失败重试、配置失效；不得覆盖未确认数据 |
| 更新与日志 | 自动检查开关持久化/24 小时节流/读书不打断；日志脱敏；未配置项目地址不伪造链接 |

HTML 验收仅证明布局、输入和本地演示状态；音量键、刷新率、缓存文件、SAF、来源签到、WebDAV 服务端和安装升级须分别提供 Android 真机与联调证据。
