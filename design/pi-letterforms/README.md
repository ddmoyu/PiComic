# PiComic · 第二轮 π 字形设计

针对第一轮 π 字形的反馈，重新绘制十二种不同结构的圆周率符号。

`index.html` / `preview.png` 使用相同黑白配色对比字形；每款附统一钴蓝底色的 48 px 图标预览。

| 编号 | 方案 | 字形变化 |
| --- | --- | --- |
| A | 几何直切 | 平直横画、利落切角 |
| B | 圆润软糖 | 圆头圆脚、饱满柔和 |
| C | 手写连笔 | 轻快斜势、自然长尾 |
| D | 经典衬线 | 粗细对比、数学书卷气 |
| E | 漫画粗黑 | 夸张大横、粗壮短脚 |
| F | 毛笔飞白 | 锋利起笔、奔放收锋 |
| G | 像素街机 | 阶梯轮廓、复古游戏感 |
| H | 折纸几何 | 斜切接笔、锐角折转 |
| I | 宽扁圆角 | 重心更低、宽横短腿 |
| J | 极细单线 | 等粗线条、轻盈留白 |
| K | 窄高标题 | 收窄横画、拉长双腿 |
| L | 断笔模板 | 留缝切断、硬朗结构 |

目录根部的十二份 SVG 是透明背景字形，`android/` 内的十二份 SVG 为同底色的 Android 图标母版，方便搭配第一轮的漫画背景。全部使用路径，不依赖系统字体。

母版画布为 108 × 108，π 的可见轮廓及描边位于中央直径 66 的安全圆内。图标预览按中央 72 × 72 区域裁切；实际接入 Android 时还需转换为 VectorDrawable，配置前景、背景及单色图标资源。

第一轮方案保留在 `../logo-concepts/`。本轮仅供字形选稿，未替换 App 启动图标。

## 重新生成

在具有 `sharp` 和 `playwright` 的 Node.js 环境运行 `node design/pi-letterforms/build.cjs`。脚本输出二十四份 SVG、自包含对比页和 PNG，检查字形安全区与页面排版。使用本机 Chrome 时，设置环境变量 `PICOM_ICON_BROWSER_CHANNEL=chrome`。
