# PiComic · 第三轮 π 字形细化

依据反馈：偏好第二轮 D 的经典衬线气质，参考 C 的手写感，重点调整横画左侧的起笔。

八款均去除原 D 左端向下的小钩。D1–D7 共用原 D 的双腿、右侧弯尾及缩放位置，便于集中比较横画；D8 融合 C 的舒展收笔。

| 编号 | 名称 | 改动 |
| --- | --- | --- |
| D1 | 平切起笔 | 左端直接平切，其余保留 D 主体 |
| D2 | 短横起笔 | 缩短横画左侧伸出部分 |
| D3 | 柔圆起笔 | 左端圆收，保持 D 的粗细对比 |
| D4 | 斜切起笔 | 左端使用斜切面，呼应双腿斜势 |
| D5 | 微弧起笔 | 横画微拱，无左端下钩 |
| D6 | 短上挑起笔 | 左端微微上扬，保留笔锋 |
| D7 | 轻横平切 | 细化横画，降低上部重量 |
| D8 | 手写融合 | D 的粗细对比与 C 的舒展弯尾结合 |

`index.html` 和 `preview.png` 提供整体字形、左端放大及 48 px 图标对比。根部的八份 SVG 为透明字形；`android/` 中的八份 SVG 为同色背景图标母版。

画布为 108 × 108。π 路径位于中央直径 66 的安全圆内，全部由矢量轮廓绘制，无字体依赖。Android 正式接入仍需转换为 VectorDrawable 并配置自适应图标资源。

本轮保留前两轮提案，未替换 App 启动图标。

## 生成预览

在有 `sharp`、`playwright` 的 Node.js 环境运行 `node design/pi-refinements/build.cjs`。使用本机 Chrome 时设置 `PICOM_ICON_BROWSER_CHANNEL=chrome`。

脚本读取 `../pi-letterforms/` 的 C、D SVG 作为对比参考。下载包中的 HTML 已嵌入这些参考图，可独立查看。
